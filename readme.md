# 🚀 Meu Primeiro Portfólio - Programa Trilhas

Bem-vindo ao repositório do meu primeiro portfólio como desenvolvedor Front-end, construído como parte do desafio do **Programa Trilhas**.

🌐 **[Acesse o Portfólio Online Aqui](https://leonardoferrza.github.io/portfolio-TRILHAS/)**

## 🎯 Sobre o Projeto
O objetivo deste desafio foi desenvolver uma página web simples, responsiva e rigorosamente alinhada a um design proposto no Figma. O portfólio apresenta meu perfil, meus interesses na área de tecnologia, links para minhas redes sociais, certificados e uma galeria dos meus projetos mais recentes.

## ✨ Funcionalidades
- **Página Inicial:** Apresentação do perfil com foto, resumo e botões de navegação.
- **Sobre Mim:** Página dedicada a detalhar minha trajetória, meu foco no ecossistema Front-end e em UI/UX.
- **Projetos:** Um layout em grade (grid) exibindo meus trabalhos práticos de destaque, como *WeNove*, *Nexus US*, e *Intel Alimentar SLZ*, com links diretos para os repositórios originais.
- **Certificados:** Acesso direto ao acervo de certificados.
- **Design Responsivo:** Adaptável a diferentes tamanhos de tela (mobile e desktop).

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização utilizando variáveis CSS (`:root`), Flexbox, CSS Grid e implementação visual inspirada em *Glassmorphism*.
- **Figma:** Extração de assets, tipografia (fonte *Inter*), paleta de cores e espaçamentos do *Style Guide* oficial.
- **Git & GitHub:** Controle de versão e versionamento de código.
- **GitHub Pages:** Deploy e hospedagem do projeto.

## 💻 Como rodar o projeto localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/leonardoferrza/portfolio-TRILHAS.git
   ```
2. Acesse a pasta do projeto no seu terminal:
   ```bash
   cd portfolio-TRILHAS
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência ou utilize a extensão **Live Server** no VS Code.
